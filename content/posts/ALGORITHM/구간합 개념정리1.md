## 🧠 개념 
#### 구간합: 배열(또는 수열)에서 어떤 구간 [L..R]의 합을 빠르게 구하는 기법으로, 핵심은 <mark>한번 미리 누적해두면, 구간 질의는 O(1)이 된다</mark>

## 🎯 언제 쓰는가 
### 구간합을 사용하는 대표 조건: 
#### 1. 같은 배열에 대해 구간 합 질의가 여러번 나올 떄 
* L~R 합을 N번 구하여라.
* 로그/매출/트래픽 시계열에서 "지난 7일의 합"같은 질의를 반복할때, 혹은 N일의 합 호출 후 N+1, N+2일의 합을 반복 증가하면서 호출할 때

```bash
index:    0    1    2    3    4
a[i]    : 2   -1    3    5   -2

prefix (길이 N+1):
p[0]=0
p[1]=0 + 2      = 2
p[2]=2 + (-1)   = 1
p[3]=1 + 3      = 4
p[4]=4 + 5      = 9
p[5]=9 + (-2)   = 7

p:       0    2    1    4    9    7
idx:     0    1    2    3    4    5

# 구간 [l=1 .. r=3] (즉 -1 + 3 + 5 = 7):
sum(1,3) = p[r+1] - p[l]
         = p[4]   - p[1]
         = 9      - 2
         = 7
         
“r까지 누적”에서 “l 전까지 누적”을 빼서 딱 [l..r]만 남기는 느낌.
```

### 🧩 Java 템플릿
```java
import java.util.*;

public class PrefixSum1D {
    // a: 0-index 배열
    // prefix: 길이 N+1, prefix[i+1] = a[0..i] 합
    static long[] buildPrefix(int[] a) {
        long[] prefix = new long[a.length + 1];
        for (int i = 0; i < a.length; i++) {
            prefix[i + 1] = prefix[i] + a[i];
        }
        return prefix;
    }

    // sum of a[l..r], inclusive
    static long rangeSum(long[] prefix, int l, int r) {
        if (l < 0 || r >= prefix.length - 1 || l > r) throw new IllegalArgumentException();
        return prefix[r + 1] - prefix[l];
    }

    public static void main(String[] args) {
        int[] a = {2, -1, 3, 5, -2};
        long[] p = buildPrefix(a);

        System.out.println(rangeSum(p, 1, 3)); // -1 + 3 + 5 = 7
        System.out.println(rangeSum(p, 0, 4)); // 전체합 = 7
        System.out.println(rangeSum(p, 2, 2)); // 3
    }
}
```

### 🧩 Kotlin 템플릿
```kotlin
object PrefixSum1D {
    // a: 0-index IntArray
    // prefix: LongArray size N+1, prefix[i+1] = sum(a[0..i])
    fun buildPrefix(a: IntArray): LongArray {
        val prefix = LongArray(a.size + 1)
        for (i in a.indices) {
            prefix[i + 1] = prefix[i] + a[i].toLong()
        }
        return prefix
    }

    // sum of a[l..r], inclusive
    fun rangeSum(prefix: LongArray, l: Int, r: Int): Long {
        require(l >= 0 && r < prefix.size - 1 && l <= r)
        return prefix[r + 1] - prefix[l]
    }
}

fun main() {
    val a = intArrayOf(2, -1, 3, 5, -2)
    val p = PrefixSum1D.buildPrefix(a)

    println(PrefixSum1D.rangeSum(p, 1, 3)) // 7
    println(PrefixSum1D.rangeSum(p, 0, 4)) // 7
    println(PrefixSum1D.rangeSum(p, 2, 2)) // 3
}
```

### 자주 나오는 변형/응용
#### 1. 구간 평균
* avg(L,R) = sum(L,R) / (R-L+1) 합을 O(1)로 구할 수 있으므로 평균도 O(1)

#### 2. 구간에 K가 몇개 있나?
* a[i] == K면, 1 or 0으로 바꾼 배열의 prefix를 만들면 구간 내 K의 개수도 rangeSum으로 바로 나온다.

#### 3. 부분합이 특정 값이 되는 구간 개수 (해시맵 + prefix)


### 예시
“연속 부분배열 합 = target”의 가장 긴 길이는 prefix + hashmap(처음 등장 index)로 O(N)
* 길이를 최대로 하려면, prefix[j] - prefix[i] = target → prefix[i] = prefix[j] - target 인 i를 찾으면 된다.
* 0-index에서 prefix를 “i까지 합”으로 두면 초기 prefix=0의 인덱스를 -1로 두는 게 깔끔하다.

``` java
import java.util.HashMap;
import java.util.Map;

public class LongestSubarraySum {
    // 합이 target인 연속 부분배열의 "최대 길이" 반환
    // 음수 포함 가능, O(N)
    public static int longestSubarrayWithSum(int[] a, long target) {
        Map<Long, Integer> firstIndex = new HashMap<>();
        firstIndex.put(0L, -1); // prefix=0이 index -1에서 시작했다고 가정 (빈 prefix)

        long prefix = 0L;
        int best = 0;

        for (int j = 0; j < a.length; j++) {
            prefix += a[j];

            long need = prefix - target;
            Integer i = firstIndex.get(need);
            if (i != null) {
                best = Math.max(best, j - i);
            }

            // "최장"을 원하므로, prefix의 최초 등장 index만 보관
            firstIndex.putIfAbsent(prefix, j);
        }

        return best;
    }

    public static void main(String[] args) {
        int[] a = {1, 2, 3, -2, 5, -3, 1, 2};
        System.out.println(longestSubarrayWithSum(a, 6)); // 예시 출력
    }
}
```

``` kotlin
object LongestSubarraySum {
    // 합이 target인 연속 부분배열의 "최대 길이" 반환
    // 음수 포함 가능, O(N)
    fun longestSubarrayWithSum(a: IntArray, target: Long): Int {
        val firstIndex = HashMap<Long, Int>()
        firstIndex[0L] = -1 // prefix=0의 "가상" 시작점

        var prefix = 0L
        var best = 0

        for (j in a.indices) {
            prefix += a[j].toLong()

            val need = prefix - target
            val i = firstIndex[need]
            if (i != null) {
                best = maxOf(best, j - i)
            }

            // prefix 최초 등장만 저장
            firstIndex.putIfAbsent(prefix, j)
        }

        return best
    }
}

fun main() {
    val a = intArrayOf(1, 2, 3, -2, 5, -3, 1, 2)
    println(LongestSubarraySum.longestSubarrayWithSum(a, 6L))
}
```
